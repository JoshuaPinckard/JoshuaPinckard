# Josh Pinckard

ToolsEnabled was founded and created by Joshua Pinckard. The original platform was developed by directing autonomous AI-agent fleets through the system's own evolving coordination architecture.

Research: agent-assisted mathematics, multi-agent coordination, concurrent file mediation, and benchmarks for LLM code generation.

## Selected work

- [Erdős Problem #1016](https://github.com/JoshuaPinckard/erdos-1016-pancyclic) (2026). Agent-assisted research on the minimum number of edges in pancyclic graphs: h(n) = 6 for 41 ≤ n ≤ 67. Upper bounds are checked in Lean 4; lower bounds rely on exhaustive computation and a shape census that is not formalized. The repository credits earlier work at n = 41 and describes the remaining gaps.
- [ToolsEnabled](https://toolsenabled.ai) (current). Software for coordinating AI-agent work. [Public projects](https://github.com/ToolsEnabled).
- [byte-interval-mediation](https://github.com/JoshuaPinckard/byte-interval-mediation) (2026). Read-receipt write admission for concurrent coding agents, with extracted implementation, tests, design probes, and recorded results.
- [agent-tree-fanout](https://github.com/JoshuaPinckard/agent-tree-fanout) (2026). Span of control for hierarchical LLM agent trees: operational data from one deployed tree, a queueing model, and a reference bound.
- LEAN-bench (2026; repository currently private). What language models do with trading-strategy specifications, graded by running generated programs in a pinned LEAN engine against a precomputed oracle bank.
- Blast-Radius (2026; design phase, repository currently private). A scoring function for predicting which regions of a repository a change may semantically invalidate.
- [MyAssistant](https://github.com/JoshuaPinckard/MyAssistant) (2025). A Windows desktop agent that reads the screen with OCR, plans with OpenAI or local models, acts through the mouse and keyboard, and verifies each step.
